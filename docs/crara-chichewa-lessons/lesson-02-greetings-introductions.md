# Chichewa — Lesson 2: Greetings and introducing yourself

**Level:** Beginner  
**Learning goal:** Practise the greetings and introductory expressions printed in the user-provided *Chichewa from English* guide.

## 1. Greetings and polite expressions

The table below transcribes the guide's own English–Chichewa pairs. The hyphens and spacing are retained where the guide prints them; this lesson does not silently standardise or correct the source.

| English in the guide | Chichewa printed in the guide |
| --- | --- |
| Hello | Moni |
| Good morning | Moni |
| How are you? | Muli bwanji? |
| I am well | Ndi-li bwino |
| Thank you | Zikomo |
| Please | Chonde |
| OK! | Chabwino |
| Excuse me | Pepani |
| Goodbye | Tsalani bwino |
| Yes / no | Inde / iyayi |
| Why? | Chifukwa? |

**Source:** *Chichewa from English*, version 4 (February 2011), page 2; the greetings/exclamations table is also on page 24.

## 2. Introducing yourself

| English in the guide | Chichewa printed in the guide |
| --- | --- |
| What is your name? | Dzina lako/lanu ndani? |
| My name is … | Dzina langa ndi- … |
| Where are you from? | Kuchokera kuti? |
| Where do you come from? | U/mu macho-kera kuti? |
| I’m from … | Ndi macho-kera ku: … |

**Source:** page 2–3 of the user-provided guide.

## 3. A short practice conversation

This is a practice dialogue assembled from separate expressions in the guide. It is not presented as a verbatim dialogue from the book.

**A:** Moni!  
**B:** Moni!  
**A:** Muli bwanji?  
**B:** Ndi-li bwino, zikomo.  
**A:** Dzina lako/lanu ndani?  
**B:** Dzina langa ndi- [your name].  
**A:** Zikomo.  
**B:** Chabwino.

The guide prints the forms above as shown. Before teaching alternative forms or claiming that every printed form is standard in all contexts, CRARA should verify it against a reliable contemporary Chichewa reference or a fluent Malawian speaker.

## 4. Practice

1. Greet someone using the word given for both “hello” and “good morning” in the guide.
2. Ask: “How are you?”
3. Reply with the guide's printed expression for “I am well.”
4. Ask someone's name.
5. Introduce yourself using the printed “My name is …” pattern.
6. Say “thank you” and “goodbye.”

### Quick recall

- What expression does the guide give for “How are you?”
- What expression does it give for “Please”?
- What expression does it give for “Thank you”?
- What is the printed question for “What is your name?”

## 5. Answer key

- **Muli bwanji?**
- **Chonde**
- **Zikomo**
- **Dzina lako/lanu ndani?**

## 6. Source-quality note

The 2011 guide contains inconsistent spelling, word spacing, hyphenation and some questionable translations elsewhere in its phrase and vocabulary lists. For that reason:

- This lesson records only the selected greeting and introduction pairs visible on pages 2–3 and 24.
- It preserves the guide's printed forms rather than quietly correcting them.
- It does not use the guide's questionable entries (for example, its printed “Cheers (appetite)” expression) as teaching targets.
- The historical dictionary is supplementary; it should not be treated as proof that every phrase in the guide is current standard usage.
- CRARA should label any unverified variant as “printed in the supplied guide” rather than asserting it as the only or universally correct form.
