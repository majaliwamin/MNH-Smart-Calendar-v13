Install MNH Calendar on your phone

Your browser completes the installation. This page only explains the steps; it cannot install the app for you.

Samsung Internet — important

Samsung Internet has a known problem creating standalone app installs on newer Android versions. If its menu shows no install option, this is a browser limitation, not a problem with the calendar. The reliable fix is to open the site in Chrome and install from there.

  1. Copy this exact address: https://mnh-smart-calendar-v13.onrender.com/
  2. Open Chrome on your phone and paste the address into the address bar.
  3. Tap the three-dot menu and choose Install app or Add to Home screen.
  4. Confirm Add / Install, then open MNH Calendar from your Home screen.

If you still want to try Samsung Internet: tap its menu (three lines or dots, usually bottom-right), or look for an install icon at the top. Choose Install app / Install on Apps screen, or Add page to → Home screen.

Chrome on Android

  1. Open the MNH Calendar link in Chrome.
  2. Tap the three-dot menu and choose Install app or Add to Home screen.
  3. Confirm the name and tap Add / Install.

iPhone or iPad

  1. Open the link in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Tap Add.

If it still does not appear

  • Use the exact HTTPS address above, not a localhost or file:// address.
  • Make sure you are online and not in private/incognito mode.
  • Reload the page once, then check the browser menu again. Some browsers need a short visit before they offer installation.
  • If the app is already installed, open it from the Home screen instead of the browser.
