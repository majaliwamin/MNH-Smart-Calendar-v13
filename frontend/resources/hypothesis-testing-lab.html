01 · Concept and research problem

A hypothesis test asks whether observed data are compatible with a claimed population value. The claim being tested is the null hypothesis, \(H_0\). The researcher's competing claim is the alternative hypothesis, \(H_1\).

Teaching order in this lab: concept → research question → hypotheses → assumptions → manual calculation → distribution → table → critical value → decision regions → decision → interpretation → Python → comparison. Python never appears before the manual stages are complete.

The worked research example

A researcher wants to know whether mean birth weight in a study population differs from 2,500 g. The illustrative information is \(n=36\), \(\bar{x}=2650\) g, population \(\sigma=450\) g and \(\alpha=0.05\), tested two-tailed. These are teaching numbers, not patient records.

02 · Manual worked example — one-sample Z-test

Open each step in order. Try the arithmetic yourself before expanding the calculation.
Step 1 — Research question

Is the population mean birth weight different from 2,500 g? The word different implies both directions, so this is a two-tailed test.

Step 2 — Hypotheses
\[H_0:\mu=2500\text{ g}\] \[H_1:\mu\ne2500\text{ g}\]

\(\mu\) is the true population mean. We test \(H_0\); we do not "prove" \(H_1\).

Step 3 — Test choice and assumptions

Use a one-sample Z-test because the population standard deviation \(\sigma\) is treated as known. Assumptions: independent observations, a random/representative sample, and approximate normality of the sampling distribution of \(\bar{x}\). With \(n=36\), the Central Limit Theorem makes the last assumption reasonable.

Step 4 — Standard error by hand
\[SE=\frac{\sigma}{\sqrt{n}}=\frac{450}{\sqrt{36}}=\frac{450}{6}=75\text{ g}\]

The standard error is the SD of the sample mean under repeated sampling.

Step 5 — Test statistic
\[z=\frac{\bar{x}-\mu_0}{SE}=\frac{2650-2500}{75}=\frac{150}{75}=2.00\]

The observed mean lies two standard errors above the claimed mean.

Step 6 — Read the Z-table (row 2.0, column 0.00)

In the standard normal table, find row 2.0, then move across to column 0.00. The cell is approximately 0.9772.

\[\Phi(2.00)\approx0.9772\]

Right tail: \(1-0.9772=0.0228\). Two-tailed p-value: \(2\times0.0228=0.0456\), which is \(0.0455\) with full precision. The small gap is table rounding only.

Step 7 — Critical values
\[\frac{\alpha}{2}=\frac{0.05}{2}=0.025\]

The Z-value with 0.025 above it is 1.96. Critical values are \(-1.96\) and \(+1.96\).

Step 8 — Distribution and rejection regions

The central 95% is the non-rejection region. Each shaded tail holds 2.5%. Scroll to the interactive normal curve to change the inputs.

Step 9 — Decision

Since \(z=2.00>1.96\), the statistic lies in the upper rejection region. Reject \(H_0\) at the 5% level.

Step 10 — Scientific interpretation

There is statistically significant evidence at the 5% level that the population mean birth weight differs from 2,500 g; the sample mean was 150 g higher. Do not equate this with clinical importance without a pre-specified clinical threshold and supporting evidence.

05 · Python in JupyterLab — only after the manual stage

Complete the manual reasoning first. You have located the table value, chosen the critical value and made the decision by hand. Only then does computation become a check rather than a shortcut.

Same research example, computational reproduction

JupyterLab cell · Python 3 · NumPy + SciPy + Matplotlib
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

# Same values used in the manual calculation
n = 36
sample_mean = 2650
mu_0 = 2500
sigma = 450
alpha = 0.05

se = sigma / np.sqrt(n)
z_stat = (sample_mean - mu_0) / se
z_critical = stats.norm.ppf(1 - alpha / 2)
p_value = 2 * stats.norm.sf(abs(z_stat))
decision = "Reject H0" if abs(z_stat) > z_critical else "Fail to reject H0"

print(f"SE = {se:.0f} g")
print(f"z = {z_stat:.2f}")
print(f"critical values = +/-{z_critical:.2f}")
print(f"p-value = {p_value:.4f}")
print(decision)

x = np.linspace(-4, 4, 400)
plt.plot(x, stats.norm.pdf(x), label="Standard normal density")
plt.axvline(-z_critical, color="orange", linestyle="--", label="Critical values")
plt.axvline(z_critical, color="orange", linestyle="--")
plt.axvline(z_stat, color="red", label="Observed z = 2.00")
plt.fill_between(x, stats.norm.pdf(x), where=x <= -z_critical, alpha=0.35)
plt.fill_between(x, stats.norm.pdf(x), where=x >= z_critical, alpha=0.35)
plt.xlabel("Z-score")
plt.ylabel("Probability density")
plt.legend()
plt.show()
Explain each line
  • import numpy as np loads NumPy for np.sqrt and numerical arrays.
  • from scipy import stats loads validated distributions: norm.pdf, norm.ppf (inverse CDF) and norm.sf (survival function).
  • import matplotlib.pyplot as plt loads the plotting library.
  • n, sample_mean, mu_0, sigma and alpha store the teaching values exactly as used by hand.
  • se reproduces \(450/\sqrt{36}=75\).
  • z_stat reproduces \((2650-2500)/75=2.00\).
  • z_critical uses ppf(0.975) to obtain 1.95996, the table's 1.96.
  • p_value doubles the upper-tail survival probability; it avoids table-rounding error.
  • decision applies the same comparison rule used manually.
  • The plot draws the same curve, critical lines and rejection regions as the SVG above.

A library is reusable tested code. NumPy handles numerical work; SciPy supplies statistical distributions; Matplotlib draws the graph. A statistical function converts a distribution and probability into a number — it does not decide the hypotheses or interpret the result.

07 · Guided practice — solutions stay hidden

Try each question before expanding a hint. Reveal the worked solution only after you have committed to an answer.
Exercise 1 · Z-table interpretation

A two-tailed test gives \(z=1.75\) at \(\alpha=0.05\). Locate the value in the Z-table, find the two-tailed p-value and make the decision.

Hint 1 — which row and column?
Use row 1.7 and column 0.05.
Hint 2 — what does the cell mean?
The cumulative probability is about 0.9599. Double the right tail.
\(\Phi(1.75)\approx0.9599\). Right tail \(=0.0401\), two-tailed p \(=0.0802\). Since 0.0802 > 0.05, fail to reject \(H_0\). Equivalently, 1.75 < 1.96.
Exercise 2 · t-table decision

For a two-tailed one-sample t-test with \(df=15\), \(t=2.10\) and \(\alpha=0.05\), find the critical value and decide.

Hint 1 — which table column?
Use the two-tailed \(\alpha=0.05\) column, not the one-tailed column.
The t-table row 15, two-tailed 0.05 column gives 2.131. Since \(|2.10|<2.131\), fail to reject \(H_0\).
Exercise 3 · chi-square critical value

A chi-square goodness-of-fit statistic is 10.5 with \(df=4\) at \(\alpha=0.05\). Locate the right-tail critical value and decide.

Hint 1 — tail direction
Chi-square tables give right-tail critical values.
For \(df=4\), right-tail \(\alpha=0.05\), the critical value is 9.488. Since 10.5 > 9.488, reject \(H_0\).
Exercise 4 · Python programming

Change the worked example to a one-tailed right test at \(\alpha=0.01\). Which two lines change, and what is the new critical value?

Hint 1 — critical line
Use stats.norm.ppf(1 - alpha) instead of dividing \(\alpha\) by two.
Set alpha = 0.01 and z_critical = stats.norm.ppf(1 - alpha). The critical value is 2.326; \(z=2.00\) is below it, so fail to reject \(H_0\).
