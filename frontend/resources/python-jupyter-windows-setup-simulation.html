Install Python on your actual Windows computer
This walkthrough is simulated. To start the real download immediately, use the official Python install manager package:
Download Python install manager (MSIX) — Python.org
Direct download from python.org. After it finishes, open the downloaded MSIX file and choose Install. This bypasses the simulated download stages.







Key terms


Python install manager
The tool from python.org that installs Python versions on Windows and provides the python, py and pymanager commands.


MSIX
A Windows app package. Double-click it and choose Install.


PATH
A list of folders Windows searches when you type a command. With the install manager, adding its folder to PATH is optional.


pip
Python’s package installer. It downloads libraries such as pandas.


Virtual environment (.venv)
A private folder that holds the packages for one project only.


JupyterLab
A browser workspace for notebooks, files and terminals.


Kernel
The Python process that runs your notebook cells. A [*] beside a cell means it is still running.


localhost
Your own computer. JupyterLab is served from it, not from the internet.


Common fixes


ProblemFix


python is not found, or opens the Microsoft StoreMake sure the install manager is installed (Stage 4). Click Start, open “Manage app execution aliases”, and turn on “Python (default)”. Check that py works.


py says “can't open file”The old Python launcher has priority. Click Start, open “Installed apps”, and uninstall “Python launcher”.


Jupyter command is not foundActivate the environment first: .venv\Scripts\activate (Stage 10), then use python -m jupyter lab.


PowerShell blocks activationUse Command Prompt, or run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once.


Browser did not openCopy the http://localhost:8888/lab?token=… link from the terminal.


ModuleNotFoundError: pandasRun python -m pip install pandas in the active environment, then restart the kernel.


Chart does not appearEnd the cell with plt.show() and run it again.




Additional troubleshooting
ProblemTry this
Python command opens Store or is not foundTry py --version, review App Execution Aliases, and consult the official Windows troubleshooting documentation.
pip command is not foundUse python -m pip --version; ensure the correct interpreter or environment is active.
ModuleNotFoundErrorInstall the missing package in the environment used by the notebook, then restart the kernel.
Notebook kernel missingInstall ipykernel into the active environment using python -m pip install ipykernel, then refresh/reselect the kernel.
Port 8888 is occupiedJupyter may choose another port. Use the URL printed by the server in the terminal.
PowerShell activation blockedPrefer Command Prompt for this walkthrough or follow official PowerShell policy guidance; avoid changing system-wide policy unnecessarily.
Plot is blankRun the plotting cell, ensure the data variables exist, and call plt.show().
Notebook cells run out of orderRestart the kernel and run cells from the top in sequence to rebuild the variables.
Official reference: Python documentation — Using Python on Windows.
