1. Thinking before testing

Hypothesis test and p-valueKuyeza mfundo ndi mtengo wa p

01

English definitionUse when you must decide whether observed data are compatible with a stated null model, such as whether a mean differs from a prespecified reference value.

Kufotokozera mu ChichewaMukayesa mfundo, mumayamba mwakhazikitsa lingaliro loti palibe kusiyana. Kenako mumafunsa: ngati lingalirolo lili loona, kodi deta yathu ingakhale yotere? p ikuyankha funso limenelo, osati funso lakuti mfundo yanu ndi yoona kapena ayi.

AnalogyFanizo A p-value is like checking how surprising a bus arrival time is under a published timetable. A very late bus is evidence against the timetable, but it does not prove the driver ignored it, and it does not tell you how much the service has changed.p ndi ngati kuyang'ana nthawi yofika basi potengera ndandanda wolembedwa. Basi ikafika mochedwa kwambiri, izi zikutsutsa ndandandawu, koma sizikutsimikizira kuti dalaivala anyalanyaza ndandanda, komanso sizikuonetsa kuchuluka kwa kusintha kwake.

Python exampleChitsanzo cha Python
import numpy as np
from scipy import stats

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112201)
values = rng.normal(loc=9.8, scale=1.6, size=40)

test = stats.ttest_1samp(values, popmean=9.0)
ci = test.confidence_interval(confidence_level=0.95)
print("n =", len(values), "mean =", round(float(values.mean()), 3))
print("t =", round(float(test.statistic), 3), "p =", round(float(test.pvalue), 4))
print("95% CI for mean =", round(float(ci.low), 3), "to", round(float(ci.high), 3))

Code explanationKufotokozera kwa code The t statistic says how many standard errors the sample mean is from the null value. A small p-value means data this extreme would be unusual if the null were true; it does not prove the alternative or measure importance.Mtengo wa t ukusonyeza kuti avareji ya sample ili kutali bwanji ndi mtengo wa null potengera standard error. p ikachepa, deta yotere ingakhale yosowa ngati null ili yoona; izi sizikutsimikizira kuti alternative ndi yoona kapena kuti zotsatira ndi zofunika.

Practical applicationKugwiritsa ntchito Comparing a cohort's mean birth weight with a national reference value, provided the reference and measurement method are appropriate.Kuyerekeza avareji ya kulemera kwa makanda ndi mtengo wadziko lonse, ngati mtengowo ndi njira yoyezera zikugwirizana.

Common misconceptionChikhulupiriro chofala cholakwika A p-value is not the probability that the null hypothesis is true. Significance depends on sample size; always report the estimate and interval.p si mwayi wakuti null ndi yoona. Kufunika kwake kumadalira kuchuluka kwa deta; nthawi zonse nenani mtengo woyerekeza ndi interval.

Effect size with confidence intervalKukula kwa zotsatira ndi confidence interval

02

English definitionUse when a p-value alone is not enough and you need to communicate how large a difference is and how precisely it has been estimated.

Kufotokozera mu ChichewaKukula kwa zotsatira kumayankha funso lakuti 'kusiyana n'kukulu bwanji?', pamene p imayankha lakuti 'kodi kusiyana kumeneku kungachitike mwangozi?'. Mafunso onse awiri ndi ofunika koma si ofanana. Gwiritsani ntchito pamene p yokha sikukwanira ndipo mukufuna kusonyeza kukula kwa kusiyana komanso kudziwa bwino kuyerekezako.

AnalogyFanizo A mean difference is like saying a harvest is 20 kg larger; Cohen's d is like saying that gain is large relative to the usual variation between harvests. Both descriptions matter.Kusiyana kwa avareji kuli ngati kunena kuti zokolola ziwonjezeka ndi 20 kg; Cohen's d ili ngati kunena kuti kuwonjezekako n'kukulu poyerekeza ndi kusiyana kwamba pakati pa zokolola. Mafotokozedwe onse awiri ndi ofunika.

Python exampleChitsanzo cha Python
import numpy as np
from scipy import stats

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112202)
control = rng.normal(3100, 420, 60)
exposed = rng.normal(3250, 430, 55)

diff = exposed.mean() - control.mean()
pooled_sd = np.sqrt(((len(control)-1)*control.var(ddof=1) +
                     (len(exposed)-1)*exposed.var(ddof=1)) /
                    (len(control)+len(exposed)-2))
d = diff / pooled_sd
J = 1 - 3/(4*(len(control)+len(exposed))-9)
g = J*d
welch = stats.ttest_ind(exposed, control, equal_var=False)
ci = welch.confidence_interval(0.95)
print("mean difference =", round(float(diff), 1))
print("Welch 95% CI =", round(float(ci.low), 1), "to", round(float(ci.high), 1))
print("Cohen d =", round(float(d), 3), "Hedges g =", round(float(g), 3))
Actual output from the fixed-seed exampleZotsatira zenizeni za chitsanzo chokhala ndi seed yokhazikika
mean difference = 134.4
Welch 95% CI = -35.8 to 304.7
Cohen d = 0.292 Hedges g = 0.29

Code explanationKufotokozera kwa code The mean difference is in the original units, so it is usually the most directly useful number. Cohen's d and Hedges' g standardise the difference; Hedges' g applies a small-sample correction.Kusiyana kwa avareji kuli mu mayunitsi oyambirira, choncho nthawi zambiri ndi nambala yothandiza kwambiri. Cohen's d ndi Hedges' g zimasintha kusiyana kukhala muyezo wofanana; Hedges' g imakonza pang'ono pazochepa.

Practical applicationKugwiritsa ntchito Quantifying how much a nutrition intervention changes mean birth weight, alongside the precision of that estimate.Kuyeza kuchuluka komwe pulogalamu ya zakudya imasintha avareji ya kulemera kwa makanda, pamodzi ndi kudziwa bwino kwa kuyerekeza kumeneko.

Common misconceptionChikhulupiriro chofala cholakwika Standardised effects can look larger in homogeneous samples and smaller in heterogeneous ones. They are not universal clinical thresholds.Zotsatira zokhazikika zingawoneke zazikulu mu deta yofanana kwambiri kapena zazing'ono mu deta yosiyana kwambiri. Sizili malire azachipatala omwe amagwiritsidwa ntchito kulikonse.

Multiple-testing correctionKukonza kwa mayeso ambiri

03

English definitionUse when you test several hypotheses in one analysis and must control either the chance of any false positive (FWER) or the expected false-discovery proportion (FDR).

Kufotokozera mu ChichewaNgati muyeza makiyi ambiri, mwayi wopeza imodzi yabodza ukuwonjezeka. Kukonza kwa mayeso ambiri kumalimbitsa muyezo wotchedwa 'significant' kuti musakhulupirire zopezeka mwangozi. Gwiritsani ntchito pamene muyeza mfundo zambiri mu kafukufuku umodzi ndipo mukufuna kuchepetsa mwayi wa zotsatira zabodza zilizonse kapena gawo la zopezeka zabodza.

AnalogyFanizo Testing many outcomes is like buying many lottery tickets. If you check enough tickets, one may look lucky; correction raises the standard for calling that luck meaningful.Kuyeza zotsatira zambiri kuli ngati kugula matikiti ambiri a lotale. Mukayang'ana ambiri, imodzi ingawoneke yamwayi; kukonzako kumakweza muyezo wotchedwa kuti mwayiwo ndi wofunika.

Python exampleChitsanzo cha Python
import numpy as np
import pandas as pd
from scipy import stats
from statsmodels.stats.multitest import multipletests

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112203)
n = 40
x = rng.normal(0, 1, (8, n))
y = rng.normal(0, 1, (8, n))
y[:2] += 0.8
p_raw = stats.ttest_ind(x, y, axis=1).pvalue

reject_holm, p_holm, _, _ = multipletests(p_raw, method="holm")
reject_bh, p_bh, _, _ = multipletests(p_raw, method="fdr_bh")
out = pd.DataFrame({"test": range(1, 9), "raw_p": p_raw.round(4),
                    "holm_p": p_holm.round(4), "bh_p": p_bh.round(4),
                    "holm_sig": reject_holm, "bh_sig": reject_bh})
print(out.to_string(index=False))

Kufotokozeratu gulu laling'ono la mayeso oyamba ndikwabwino kukonza kusaka kopanda malire.

Power and sample sizeMphamvu ya mayeso ndi kukula kwa sample

04

English definitionUse at the design stage to decide how many participants are needed to detect an effect of practical interest with acceptable power, or to calculate the power of a planned sample size.

Kufotokozera mu ChichewaMphamvu ndi mwayi wozindikira kusiyana ngati kusiyana kwenikweni kulipo. Sample ikachepa, ngakhale mankhwala angathandize, kafukufuku angaphonye kuzindikira. Gwiritsani ntchito popanga kafukufuku kuti mudziwe ochita nawo kafukufuku angati omwe akufunika kuti azindikire zotsatira zofunika, kapena kuwerengera mphamvu ya sample yomwe yakonzedwa.

AnalogyFanizo Power is like using a net with a certain mesh size. A fine enough net catches small fish; a coarse net may let them escape even when they are present.Mphamvu ili ngati ukonde wokhala ndi mabowo a kukula kwake. Ukonde wabwino ugwira nsomba zazing'ono; wokhala ndi mabowo akulu ukhoza kuzilola kuthawa ngakhale zilipo.

Python exampleChitsanzo cha Python
import numpy as np
from statsmodels.stats.power import TTestIndPower
from statsmodels.stats.proportion import proportion_effectsize

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112204)
pilot_control = rng.binomial(1, 0.20, 80)
pilot_treated = rng.binomial(1, 0.32, 80)
effect = abs(proportion_effectsize(pilot_treated.mean(), pilot_control.mean()))
analysis = TTestIndPower()
n_each = analysis.solve_power(effect_size=effect, alpha=0.05,
                              power=0.80, ratio=1.0,
                              alternative="two-sided")
power_60 = analysis.power(effect_size=effect, nobs1=60, alpha=0.05,
                          ratio=1.0, alternative="two-sided")
print("pilot proportions =", round(pilot_control.mean(), 3),
      "and", round(pilot_treated.mean(), 3))
print("standardised effect =", round(float(effect), 3))
print("n per group for 80% power =", int(np.ceil(n_each)))
print("power with 60 per group =", round(float(power_60), 3))

Code explanationKufotokozera kwa code The pilot proportions provide a crude standardised effect. The required n is per group for a two-sided test at alpha 0.05.Zigawo za pilot zimapereka kuyerekeza kwa zotsatira zokhazikika. n yofunikira ndi pa gulu limodzi pa mayeso awiri a alpha 0.05.

Sampling variability and standard errorKusiyana kwa sample ndi standard error

05

English definitionUse when you want to understand why two samples from the same population give different estimates, and how much an estimate typically varies across repeated samples.

Kufotokozera mu ChichewaNgati mutenga magulu ang'onoang'ono ambiri kuchokera ku gulu limodzi, avareji yawo simakhala yofanana nthawi zonse. Kufalikira kwa ma avareji amenewo kumatiuza kuchuluka kwa kusatsimikizika kwa kuyerekeza kumodzi. Gwiritsani ntchito pamene mukufuna kumvetsetsa chifukwa chake sample ziwiri zachokera ku gulu limodzi zimapereka zotsatira zosiyana, komanso kuchuluka kwa kusiyana kwake.

AnalogyFanizo Standard error is like the spread of repeated spoonfuls from a well-mixed pot. One spoonful may differ, but the average of many spoonfuls is stable.Standard error ili ngati kusiyana kwa supuni zambiri zotengedwa mu mphika wosakanizidwa bwino. Supuni imodzi ingasiyane, koma avareji ya supuni zambiri imakhala yokhazikika.

import numpy as np

print("mean of 2000 sample means =", round(float(means.mean()), 2))
print("SD of sample means =", round(float(means.std(ddof=1)), 2))
print("theoretical SE =", round(float(se_theory), 2))

Permutation test logicMalingaliro a permutation test

06

English definitionUse when you want a distribution-free way to test a sharp null hypothesis, especially with small samples or a statistic whose theoretical distribution is awkward.

Kufotokozera mu ChichewaNgati palibe kusiyana kwenikweni, zilembo za gulu A ndi B ziyenera kusinthasintha mofanana. Timasakaniza zilembowo mobwerezabwereza kuti tiwone kodi kusiyana kwathu kuli kodabwitsa bwanji. Gwiritsani ntchito pamene mukufuna kuyesa mfundo ya null popanda kudalira mtundu wa kufalikira, makamaka ngati deta ndi yochepa kapena chiwerengerocho chili chovuta kuwerengera.

AnalogyFanizo It is like shuffling team labels on a list of runners. If the labels do not matter, many shuffles will produce differences as large as the one you saw.Zili ngati kusakaniza zilembo za magulu a othamanga. Ngati zilembozo sizifunika, kusakaniza kwambiri kudzatulutsa kusiyana kofanana kapena kokulirapo ndi komwe munawona.

Python exampleChitsanzo cha Python
import numpy as np

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112206)
group_a = rng.normal(12.0, 2.0, 14)
group_b = rng.normal(14.2, 2.0, 14)
observed = group_b.mean() - group_a.mean()
pooled = np.concatenate([group_a, group_b])
n_a = len(group_a)
count = 0
B = 20000
for _ in range(B):
    shuffled = rng.permutation(pooled)
    stat = shuffled[n_a:].mean() - shuffled[:n_a].mean()
    if abs(stat) >= abs(observed) - 1e-12:
        count += 1
print("observed difference =", round(float(observed), 3))
print("two-sided permutation p =", round((count + 1)/(B + 1), 4))

observed difference = 1.926
two-sided permutation p = 0.005

Code explanationKufotokozera kwa code The permutation p-value is the fraction of randomly reassigned datasets with a difference at least as extreme as the observed one. It uses the data's own rearrangement as the reference distribution instead of a textbook formula.p ya permutation ndi gawo la deta yosinthidwa mwachisawawa yomwe kusiyana kwake kuli kokulirapo kapena kofanana ndi kowonedwa. Imagwiritsa ntchito kusinthasintha kwa deta yeniyeni m'malo mwa formula ya buku.

Practical applicationKugwiritsa ntchito Comparing a small pilot group with a control when a parametric assumption is doubtful.Kuyerekeza gulu laling'ono la pilot ndi gulu lolamulira pamene mfundo za parametric zikukayikiridwa.

Common misconceptionChikhulupiriro chofala cholakwika Exchangeability is a strong assumption and can fail with unequal variances, time trends or clustering. With very few possible permutations the minimum p-value is coarse.Kusinthana kungakhale kolimba ndipo kungalephere ngati variances zosiyana, nthawi kapena magulu ogwirizana. Ngati kusinthana kochepa, p yocheperako imakhala yosakhwima.

2. Comparing groups

Independent samples t-testt-test ya magulu odziyimira pawokha

07

English definitionStudent's independent-samples t-test compares the means of two unrelated groups by dividing their mean difference by a pooled standard error. It assumes a common within-group variance.

Kufotokozera mu ChichewaMayesowa uyerekeza avareji a magulu awiri osiyana. 'Independent' kutanthauza kuti munthu aliyense ali mugulu limodzi lokha, kotero palibe awiriawiri ofanana pakati pa maguluwo. Umagwiritsa ntchito kufalikira kwa magulu onse kuti uone kusiyana kwa avareji kuli kwakukulu kuposa phokoso la deta.

AnalogyFanizo Like comparing the average harvest of two separate farms: each farm contributes one yield per plot, and the question is whether the gap exceeds ordinary variation between plots.Zili ngati kuyerekeza zokolola zapakati pa mafakitale awiri osiyana: famu iliyonse imapereka zokolola kamodzi pa malo aliwonse, ndipo funso ndi kuti kusiyana kwake kuli kwakukulu kuposa kusiyana kwamba.

Python exampleChitsanzo cha Python
import numpy as np
from scipy import stats

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112240)
standard = rng.normal(3200, 380, 55)
new_care = rng.normal(3330, 390, 48)

res = stats.ttest_ind(new_care, standard, equal_var=True)
ci = res.confidence_interval(0.95)
print("means =", round(float(standard.mean()), 1), "and",
      round(float(new_care.mean()), 1))
print("pooled t =", round(float(res.statistic), 3),
      "df =", round(float(res.df), 1), "p =", round(float(res.pvalue), 4))
print("95% CI for difference =", round(float(ci.low), 1), "to",
      round(float(ci.high), 1))

pooled t = 1.498 df = 101.0 p = 0.1372

Code explanationKufotokozera kwa code equal_var=True pools the two variances. ttest_ind returns the t statistic, degrees of freedom and p-value; confidence_interval() adds the plausible range for the mean difference.equal_var=True imaphatikiza variances ziwirizo kukhala chimodzi. ttest_ind imapereka t, degrees of freedom ndi p; confidence_interval() imawonjezera mtunda wotheka wa kusiyana kwa avareji.

Practical applicationKugwiritsa ntchito Comparing mean birth weight between two independently sampled regions when their spreads are similar.Kuyerekeza avareji ya kulemera kwa makanda pakati pa madera awiri osiyana pamene kufalikira kwawo kuli kofanana.

Common misconceptionChikhulupiriro chofala cholakwika It is not a paired test, and equal variances are an assumption rather than a guaranteed fact. A significant result does not prove that the groups differ for causal reasons.Si paired test, ndipo variances zofanana ndi mfundo yongoganizira, osati yotsimikizika. Zotsatira zofunika sizikutsimikizira kuti kusiyana kunachitika chifukwa cha chinthu chinachake.

Welch's t-testWelch's t-test ya magulu awiri

08

English definitionWelch's t-test compares the means of two independent groups without assuming equal variances. It adjusts the degrees of freedom to account for unequal spread.

Kufotokozera mu ChichewaWelch imafunsa kuti avareji ya magulu awiri odziyimira pawokha ndi yosiyana kwambiri poyerekeza ndi kufalikira kwa deta. Simafuna kuti magulu awiriwo akhale ndi variances zofanana, choncho ndi yotetezeka pa deta yeniyeni.

AnalogyFanizo Comparing two classrooms with different spreads of marks: Welch adjusts for the fact that one class may be much more variable than the other.Kuyerekeza makalasi awiri omwe mphambu zawo zimafalikira mosiyanasiyana: Welch imaganizira kuti kalasi imodzi ikhoza kukhala yosiyana kwambiri ndi inzake.

Python exampleChitsanzo cha Python
import numpy as np
import pandas as pd

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112242)
n = 200
group = rng.integers(0, 2, n)
true_value = 10 + 1.5*group + rng.normal(0, 2, n)
observed = true_value.copy()
missing_prob = np.where(group == 1, 0.30, 0.10)
missing = rng.random(n) < missing_prob
observed[missing] = np.nan
df = pd.DataFrame({"group": group, "value": observed})

def diff_after_delta(delta):
    filled = df.copy()
    for g in [0, 1]:
        median_g = filled.loc[filled["group"] == g, "value"].median()
        mask = (filled["group"] == g) & filled["value"].isna()
        filled.loc[mask, "value"] = median_g + delta*g
    return filled.loc[filled["group"] == 1, "value"].mean() -            filled.loc[filled["group"] == 0, "value"].mean()

complete = df.dropna()
cc_diff = complete.loc[complete["group"] == 1, "value"].mean() - \
          complete.loc[complete["group"] == 0, "value"].mean()
print("missing rate by group =",
      df.groupby("group")["value"].apply(lambda s: round(s.isna().mean(), 3)).to_dict())
print("complete-case difference =", round(float(cc_diff), 3))
for delta in [-1.0, 0.0, 1.0]:
    print("delta scenario", delta, "difference =",
          round(float(diff_after_delta(delta)), 3))
