from scipy import stats

rng = np.random.default_rng(2026112201)
values = rng.normal(loc=9.8, scale=1.6, size=40)

print("t =", round(float(test.statistic), 3), "p =", round(float(test.pvalue), 4))

Effect size with confidence intervalKukula kwa zotsatira ndi confidence interval

02

Use whenGwiritsani ntchito pamene Use when a p-value alone is not enough and you need to communicate how large a difference is and how precisely it has been estimated.Gwiritsani ntchito pamene p yokha sikukwanira ndipo mukufuna kusonyeza kukula kwa kusiyana komanso kudziwa bwino kuyerekezako.

Assumptions / design checksMfundo zofunikira / kuyang'ana kapangidwe The two groups are independent; the outcome is continuous; Cohen's d assumes comparable within-group spread. Welch's interval does not require equal variances but still relies on approximate normality of the group means.Magulu awiri ndi odziyimira pawokha; zotsatira ndi za manambala; Cohen's d imaganizira kufanana kwa kufalikira mkati mwa magulu. Welch interval safuna kuti variances zikhale zofanana koma imadalira kuti avareji azikhala pafupifupi normal.

Self-contained Python exampleChitsanzo cha Python chodziyimira pawokha
import numpy as np
from scipy import stats

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112202)
control = rng.normal(3100, 420, 60)
exposed = rng.normal(3250, 430, 55)

diff = exposed.mean() - control.mean()
pooled_sd = np.sqrt(((len(control)-1)*control.var(ddof=1) +
                     (len(exposed)-1)*exposed.var(ddof=1)) /
                    (len(control)+len(exposed)-2))
d = diff / pooled_sd
J = 1 - 3/(4*(len(control)+len(exposed))-9)
g = J*d
welch = stats.ttest_ind(exposed, control, equal_var=False)
ci = welch.confidence_interval(0.95)
print("mean difference =", round(float(diff), 1))
print("Welch 95% CI =", round(float(ci.low), 1), "to", round(float(ci.high), 1))
print("Cohen d =", round(float(d), 3), "Hedges g =", round(float(g), 3))

Cohen's d and Hedges' g standardise the difference; Hedges' g applies a small-sample correction. The CI shows the range of differences compatible with the data under the model.Kusiyana kwa avareji kuli mu mayunitsi oyambirira, choncho nthawi zambiri ndi nambala yothandiza kwambiri. Cohen's d ndi Hedges' g zimasintha kusiyana kukhala muyezo wofanana; Hedges' g imakonza pang'ono pazochepa. CI imasonyeza kusiyana kotheka potengera deta ndi model.

Limitations and mistakes to avoidMalire ndi zolakwika zoyenera kupewa Standardised effects can look larger in homogeneous samples and smaller in heterogeneous ones. They are not universal clinical thresholds. Report the raw units and the population context beside any d or g value.Zotsatira zokhazikika zingawoneke zazikulu mu deta yofanana kwambiri kapena zazing'ono mu deta yosiyana kwambiri. Sizili malire azachipatala omwe amagwiritsidwa ntchito kulikonse. Nenani mayunitsi oyambirira ndi mbiri ya anthu pamodzi ndi d kapena g iliyonse.

Plain-language ideaLingaliro m'mawu osavuta Effect size with confidence interval answers a specific design question: Use when a p-value alone is not enough and you need to communicate how large a difference is and how precisely it has been estimated. The fixed-seed example shows what the method computes and how the result should be read; it is not a universal decision rule.Kukula kwa zotsatira kumayankha funso lakuti 'kusiyana n'kukulu bwanji?', pamene p imayankha lakuti 'kodi kusiyana kumeneku kungachitike mwangozi?'. Mafunso onse awiri ndi ofunika koma si ofanana.

Both descriptions matter.Kusiyana kwa avareji kuli ngati kunena kuti zokolola ziwonjezeka ndi 20 kg; Cohen's d ili ngati kunena kuti kuwonjezekako n'kukulu poyerekeza ndi kusiyana kwamba pakati pa zokolola. Mafotokozedwe onse awiri ndi ofunika.

How to report itMomwe mungafotokozere State the raw mean difference with 95% CI, then the standardised effect if useful. Name the population, units and group definitions.Nenani kusiyana kwa avareji ndi 95% CI, kenako zotsatira zokhazikika ngati zikuthandiza. Tchulani gulu la anthu, mayunitsi ndi matanthauzo a magulu.

Multiple-testing correctionKukonza kwa mayeso ambiri

03

Use whenGwiritsani ntchito pamene Use when you test several hypotheses in one analysis and must control either the chance of any false positive (FWER) or the expected false-discovery proportion (FDR).Gwiritsani ntchito pamene muyeza mfundo zambiri mu kafukufuku umodzi ndipo mukufuna kuchepetsa mwayi wa zotsatira zabodza zilizonse kapena gawo la zopezeka zabodza.

Assumptions / design checksMfundo zofunikira / kuyang'ana kapangidwe The family of tests should be defined before analysis. p-values must be valid individually. Holm controls family-wise error and is appropriate for a small confirmatory family; Benjamini-Hochberg controls FDR and is common in exploratory screening.Gulu la mayeso liyenera kufotokozedwa musanayambe kusanthula. p ya mayeso aliyonse iyenera kukhala yovomerezeka. Holm imachepetsa mwayi wa zolakwika zilizonse; Benjamini-Hochberg imachepetsa gawo la zopezeka zabodza ndipo imagwiritsidwa ntchito kwambiri pakufufuza koyambirira.

Self-contained Python exampleChitsanzo cha Python chodziyimira pawokha
import numpy as np
import pandas as pd
from scipy import stats
from statsmodels.stats.multitest import multipletests

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112203)
n = 40
x = rng.normal(0, 1, (8, n))
y = rng.normal(0, 1, (8, n))
y[:2] += 0.8
p_raw = stats.ttest_ind(x, y, axis=1).pvalue

reject_holm, p_holm, _, _ = multipletests(p_raw, method="holm")
reject_bh, p_bh, _, _ = multipletests(p_raw, method="fdr_bh")
out = pd.DataFrame({"test": range(1, 9), "raw_p": p_raw.round(4),
                    "holm_p": p_holm.round(4), "bh_p": p_bh.round(4),
                    "holm_sig": reject_holm, "bh_sig": reject_bh})
print(out.to_string(index=False))

04

Use whenGwiritsani ntchito pamene Use at the design stage to decide how many participants are needed to detect an effect of practical interest with acceptable power, or to calculate the power of a planned sample size.Gwiritsani ntchito popanga kafukufuku kuti mudziwe ochita nawo kafukufuku angati omwe akufunika kuti azindikire zotsatira zofunika, kapena kuwerengera mphamvu ya sample yomwe yakonzedwa.

Assumptions / design checksMfundo zofunikira / kuyang'ana kapangidwe You must specify effect size, alpha, desired power, allocation ratio and the test. Pilot effect estimates are uncertain, so a range of plausible effects should be examined rather than a single optimistic number.Muyenera kufotokoza kukula kwa zotsatira, alpha, mphamvu yofunidwa, chiŵerengero cha magulu ndi mayeso. Self-contained Python exampleChitsanzo cha Python chodziyimira pawokha
import numpy as np
from statsmodels.stats.power import TTestIndPower
from statsmodels.stats.proportion import proportion_effectsize

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112204)
pilot_control = rng.binomial(1, 0.20, 80)
pilot_treated = rng.binomial(1, 0.32, 80)
effect = abs(proportion_effectsize(pilot_treated.mean(), pilot_control.mean()))
analysis = TTestIndPower()
n_each = analysis.solve_power(effect_size=effect, alpha=0.05,
                              power=0.80, ratio=1.0,
                              alternative="two-sided")
power_60 = analysis.power(effect_size=effect, nobs1=60, alpha=0.05,
                          ratio=1.0, alternative="two-sided")
print("pilot proportions =", round(pilot_control.mean(), 3),
      "and", round(pilot_treated.mean(), 3))
print("standardised effect =", round(float(effect), 3))
print("n per group for 80% power =", int(np.ceil(n_each)))
print("power with 60 per group =", round(float(power_60), 3))

05

Use whenGwiritsani ntchito pamene Use when you want to understand why two samples from the same population give different estimates, and how much an estimate typically varies across repeated samples.Gwiritsani ntchito pamene mukufuna kumvetsetsa chifukwa chake sample ziwiri zachokera ku gulu limodzi zimapereka zotsatira zosiyana, komanso kuchuluka kwa kusiyana kwake.

Assumptions / design checksMfundo zofunikira / kuyang'ana kapangidwe Samples are independent and drawn from the same population; the statistic has a finite variance. The simulation below uses a known synthetic population so the true value is available for teaching only.Ma sample ndi odziyimira pawokha ndipo achokera ku gulu limodzi; chiwerengerocho chili ndi variance yochepa. Self-contained Python exampleChitsanzo cha Python chodziyimira pawokha
import numpy as np

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112205)
population = rng.lognormal(mean=7.0, sigma=0.35, size=50000)
true_mean = population.mean()
means = np.array([rng.choice(population, size=50, replace=True).mean()
                  for _ in range(2000)])
se_theory = population.std(ddof=1) / np.sqrt(50)
print("true simulated population mean =", round(float(true_mean), 2))
print("mean of 2000 sample means =", round(float(means.mean()), 2))
print("SD of sample means =", round(float(means.std(ddof=1)), 2))
print("theoretical SE =", round(float(se_theory), 2))

Permutation test logicMalingaliro a permutation test

06

Use whenGwiritsani ntchito pamene Use when you want a distribution-free way to test a sharp null hypothesis, especially with small samples or a statistic whose theoretical distribution is awkward.Gwiritsani ntchito pamene mukufuna kuyesa mfundo ya null popanda kudalira mtundu wa kufalikira, makamaka ngati deta ndi yochepa kapena chiwerengerocho chili chovuta kuwerengera.

Assumptions / design checksMfundo zofunikira / kuyang'ana kapangidwe Under the sharp null, observations are exchangeable between groups. The resampling must respect the design; do not permute paired or clustered observations as if they were independent.Pansi pa null yokhwima, ma observation ayenera kusinthana pakati pa magulu. Kusankhanso kuyenera kulemekeza kapangidwe ka kafukufuku; musasinthane ma observation ogwirizana kapena a gulu ngati kuti ndi odziyimira pawokha.

Self-contained Python exampleChitsanzo cha Python chodziyimira pawokha
import numpy as np

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112206)
group_a = rng.normal(12.0, 2.0, 14)
group_b = rng.normal(14.2, 2.0, 14)
observed = group_b.mean() - group_a.mean()
pooled = np.concatenate([group_a, group_b])
n_a = len(group_a)
count = 0
B = 20000
for _ in range(B):
    shuffled = rng.permutation(pooled)
    stat = shuffled[n_a:].mean() - shuffled[:n_a].mean()
    if abs(stat) >= abs(observed) - 1e-12:
        count += 1
print("observed difference =", round(float(observed), 3))
print("two-sided permutation p =", round((count + 1)/(B + 1), 4))

Self-contained Python exampleChitsanzo cha Python chodziyimira pawokha
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols
from statsmodels.stats.multicomp import pairwise_tukeyhsd

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112211)
rows = []
for group, shift in [("standard", 0), ("low_dose", 150), ("high_dose", 300)]:
    values = rng.normal(3100 + shift, 250, 45)
    rows.extend([(group, float(v)) for v in values])
df = pd.DataFrame(rows, columns=["group", "birth_weight"])

model = ols("birth_weight ~ C(group)", data=df).fit()
aov = sm.stats.anova_lm(model, typ=2)
f_row = aov.loc["C(group)"]
print("ANOVA F =", round(float(f_row["F"]), 3),
      "p =", format(float(f_row["PR(>F)"]), ".3g"))
tukey = pairwise_tukeyhsd(df["birth_weight"], df["group"], alpha=0.05)
for i in range(len(tukey.meandiffs)):
    print(tukey.group_c[i], "vs", tukey.group_t[i],
          "mean difference =", round(float(tukey.meandiffs[i]), 1),
          "adjusted p =", format(float(tukey.pvalues[i]), ".3g"),
          "95% CI", round(float(tukey.confint[i][0]), 1), "to",
          round(float(tukey.confint[i][1]), 1),
          "reject =", bool(tukey.reject[i]))

import numpy as np
from scipy import stats
from statsmodels.stats.inter_rater import cohens_kappa

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112218)
true_class = rng.integers(0, 2, 160)
rater_a = true_class.copy()
rater_b = true_class.copy()
disagree = rng.choice(160, size=34, replace=False)
rater_b[disagree] = 1 - rater_b[disagree]
table = np.zeros((2, 2), dtype=int)
for a, b in zip(rater_a, rater_b):
    table[a, b] += 1

res = cohens_kappa(table)
print("confusion table rows=rater A, cols=rater B")
print(table)
print("observed agreement =", round(float(np.trace(table)/table.sum()), 3))

outcome = 2.2*score + rng.lognormal(0, 0.5, 90)

print("approx 95% CI =", round(float(lo), 3), "to", round(float(hi), 3))

def residuals(target, controls):
    X = np.column_stack([np.ones(len(target))] + [df[c].to_numpy() for c in controls])
    beta = np.linalg.lstsq(X, np.asarray(target), rcond=None)[0]
    return np.asarray(target) - X @ beta

ry = residuals(df["outcome"], ["age"])
partial = np.corrcoef(rx, ry)[0, 1]
crude = df["biomarker"].corr(df["outcome"])
print("crude Pearson r =", round(float(crude), 3))
print("partial r controlling age =", round(float(partial), 3))

import pandas as pd
import statsmodels.api as sm

rows = []

    base = rng.normal(0, 0.6)
    for visit in [0, 1, 2]:
        group = pid % 2

          "p =", round(float(gee.pvalues[name]), 4))

print("sensitivity =", round(tp/(tp+fn), 3),

      [[int(tn), int(fp)], [int(fn), int(tp)]])

import pandas as pd
import statsmodels.formula.api as smf

# SIMULATED TEACHING DATA — not real patient records.

n = 220

y = 0.4*m + 0.3*x + 0.2*c + rng.normal(0, 0.9, n)

a = smf.ols("m ~ x + c", data=df).fit().params["x"]
b = smf.ols("y ~ m + x + c", data=df).fit().params["m"]
cp = smf.ols("y ~ x + c", data=df).fit().params["x"]

print("b path =", round(float(b), 3))

print("total effect =", round(float(indirect + cp), 3))

import numpy as np
import pandas as pd

# SIMULATED TEACHING DATA — not real patient records.
rng = np.random.default_rng(2026112242)
n = 200
group = rng.integers(0, 2, n)
true_value = 10 + 1.5*group + rng.normal(0, 2, n)
observed = true_value.copy()
missing_prob = np.where(group == 1, 0.30, 0.10)
missing = rng.random(n) < missing_prob
observed[missing] = np.nan
df = pd.DataFrame({"group": group, "value": observed})

def diff_after_delta(delta):
    filled = df.copy()
    for g in [0, 1]:
        median_g = filled.loc[filled["group"] == g, "value"].median()
        mask = (filled["group"] == g) & filled["value"].isna()
        filled.loc[mask, "value"] = median_g + delta*g
    return filled.loc[filled["group"] == 1, "value"].mean() -            filled.loc[filled["group"] == 0, "value"].mean()

complete = df.dropna()
cc_diff = complete.loc[complete["group"] == 1, "value"].mean() - \
          complete.loc[complete["group"] == 0, "value"].mean()
print("missing rate by group =",
      df.groupby("group")["value"].apply(lambda s: round(s.isna().mean(), 3)).to_dict())
print("complete-case difference =", round(float(cc_diff), 3))
for delta in [-1.0, 0.0, 1.0]:
    print("delta scenario", delta, "difference =",
          round(float(diff_after_delta(delta)), 3))
