Inspect, then check duplicates, missingness, implausible values and logic. Complete-case analysis loses power and can bias; mean/median imputation shrinks variance; multiple imputation (e.g. statsmodels MICE) propagates uncertainty and is preferred when data are missing at random.

  • Compare complete-case and imputed results side by side.
  • Require a written cleaning log.
  • Visualise missingness patterns by group.
  • Test whether missingness depends on observed variables.
  • Compare MICE results across five imputations.

Chapter 8: Hypothesis tests

A p-value is the probability of data at least as extreme as observed if the null is true; it is not the probability the null is true and says nothing about effect size. Always report estimate, CI and clinical meaning. Choose: 2 groups continuous normal -> t-test/Welch; non-normal -> Mann-Whitney; >2 groups -> ANOVA/Kruskal-Wallis; categorical -> chi-square/Fisher; paired -> paired t/Wilcoxon/McNemar.

Teaching and advanced learning clues
  • Explain p-values with a coin-flip simulation.
  • Ask learners to restate a p-value in plain words.
  • Contrast statistical and clinical significance with real effect sizes.
  • Run a power calculation before a study.
  • Simulate Type I error inflation from repeated testing.
  • Compare Bonferroni and FDR.
